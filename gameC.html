🎮 Консольная игра "Путь героя"

📖 Описание игры

Вам предстоит создать пошаговую RPG-игру в консоли. Ваш герой сражается с 5 противниками, после каждой победы повышая свои характеристики. Игра должна быть полностью интерактивной, с системой боя, прокачкой и отображением состояния героя.

⚔️ Требования к игре

1. Герой

У героя должно быть 5 параметров:

  • ❤️ Здоровье (HP) — при достижении 0 игра заканчивается поражением
  • ⚔️ Сила (Strength) — влияет на наносимый урон
  • 🛡️ Защита (Defense) — уменьшает входящий урон
  • 🎯 Ловкость (Agility) — влияет на шанс критического удара
  • ✨ Удача (Luck) — влияет на уклонение от атак

2. Противники (5 штук)

Каждый противник должен быть уникальным. Создайте 5 разных типов врагов:

  • Гоблин — слабый, но ловкий
  • Орк — сильный, но медленный
  • Тролль — высокое здоровье, низкая защита
  • Тёмный рыцарь — сбалансированный
  • Босс (Дракон) — финальный противник, очень сильный

3. Система боя

  • Бой пошаговый: игрок выбирает действие (атаковать, использовать зелье, попытаться сбежать)
  • Расчёт урона: урон = сила_атакующего - защита_цели + случайное_значение
  • Критический удар: если ловкость > случайного числа → урон × 2
  • Уклонение: если удача > случайного числа → атака промахивается
  • После каждого боя герой восстанавливает часть здоровья

4. Система прокачки

После победы над противником игрок получает 3 очка улучшения, которые можно распределить между 5 параметрами. Каждое очко увеличивает соответствующий параметр на 1.

5. Отображение состояния

В начале боя и после каждого хода должно отображаться состояние героя и текущего противника.

📝 Структура программы

// Структура героя struct Hero { std::string name; int hp; // текущее здоровье int maxHp; // максимальное здоровье int strength; // сила int defense; // защита int agility; // ловкость (шанс крита) int luck; // удача (шанс уклонения) int potions; // количество зелий лечения }; // Структура противника struct Enemy { std::string name; int hp; int maxHp; int strength; int defense; int agility; int luck; int expReward; // опыт (не используется, но можно добавить) };

Функции, которые необходимо реализовать:

  • void displayHero(const Hero& hero) — отображение состояния героя
  • void displayEnemy(const Enemy& enemy) — отображение состояния противника
  • int calculateDamage(int attackerStrength, int targetDefense) — расчёт урона
  • bool isCritical(int agility) — проверка критического удара
  • bool isEvasion(int luck) — проверка уклонения
  • void usePotion(Hero& hero) — использование зелья
  • void upgradeHero(Hero& hero, int points) — прокачка героя
  • bool fight(Hero& hero, Enemy& enemy) — бой с противником (возвращает true при победе)
  • Enemy createEnemy(int level) — создание противника в зависимости от уровня

🎯 Дополнительные требования к функционалу

  • Использование указателей для передачи больших структур в функции (или константных ссылок)
  • Использование перегрузки функций (например, для отображения разных типов существ)
  • Использование массива противников или std::vector
  • Обработка некорректного ввода пользователя
  • Очистка консоли после каждого хода (system("cls") или system("clear"))
  • Добавление случайности с помощью rand() и srand(time(0))
