Массивы в параметрах функций в C++

📘 Способы передачи массивов в функции:
• void func(int arr[], int size) — классический способ
• void func(int* arr, int size) — через указатель
• void func(int arr[10]) — с указанием фиксированного размера
• void func(const int arr[], int size) — константный массив
• void func(int (&arr)[10]) — ссылка на массив фиксированного размера

Способы передачи массивов в функции

Способ Синтаксис Передача массива Изменение оригинала
Как массив void f(int arr[], int n) по адресу да
Как указатель void f(int* arr, int n) по значению (копия указателя) да (через разыменование)
Как ссылка на массив void f(int (&arr)[10]) по ссылке да
Константный массив void f(const int arr[], int n) по адресу нет

Стандартный массив Анализ успеваемости

Создайте программу для анализа оценок студентов:

  1. Реализуйте функцию void analyzeScores(const int scores[], int size, double& average, int& max, int& min), которая:
    • Вычисляет среднее арифметическое всех оценок
    • Находит максимальную и минимальную оценку
    • Возвращает результаты через ссылки
  2. Реализуйте функцию int countAboveAverage(const int scores[], int size, double average), которая считает количество оценок выше среднего.
  3. В функции main() создайте массив оценок (размер 10), заполните его вводом пользователя.
  4. Выведите результаты анализа.
💡 При передаче массива: const int scores[] — массив не будет изменён внутри функции.
Пример ввода/вывода: Введите 10 оценок: 5 4 5 3 5 4 4 5 3 4 Средний балл: 4.2 Максимум: 5 Минимум: 3 Количество оценок выше среднего: 6

Указатель на массив Объединение и сортировка

Напишите программу, которая:

  1. Реализует функцию void mergeArrays(const int* arr1, int size1, const int* arr2, int size2, int* result, int& resultSize) — объединяет два отсортированных массива в один отсортированный.
  2. Реализует функцию void sortArray(int* arr, int size) — сортирует массив по возрастанию (любым алгоритмом).
  3. Реализует функцию void printArray(const int* arr, int size) — выводит массив.
  4. В main() создайте два массива, заполните их случайными числами, отсортируйте каждый, затем объедините и выведите результат.
💡 Указатели и массивы: Имя массива — это указатель на его первый элемент. int* arr и int arr[] в параметрах функций эквивалентны.
Пример вывода: Массив 1: 2 5 7 9 Массив 2: 1 3 6 8 10 Результат слияния: 1 2 3 5 6 7 8 9 10

Ссылка на массив Работа с матрицами

Создайте программу для работы с матрицей 3×3:

  1. Реализуйте функцию void inputMatrix(int (&matrix)[3][3]) — заполняет матрицу значениями от 1 до 9 (или вводом пользователя).
  2. Реализуйте функцию void printMatrix(const int (&matrix)[3][3]) — выводит матрицу на экран в виде таблицы.
  3. Реализуйте функцию void transposeMatrix(int (&matrix)[3][3]) — транспонирует матрицу (меняет строки и столбцы).
  4. Реализуйте функцию int sumDiagonal(const int (&matrix)[3][3]) — возвращает сумму элементов главной диагонали.
  5. В main() продемонстрируйте работу всех функций.
💡 Ссылка на массив: int (&matrix)[3][3] — передача массива по ссылке, размер строго фиксирован.
Пример вывода: Исходная матрица: 1 2 3 4 5 6 7 8 9 Транспонированная матрица: 1 4 7 2 5 8 3 6 9 Сумма диагонали: 15

Динамические массивы Библиотека книг

Создайте программу для управления библиотекой книг:

  1. Структура struct Book { char title[50]; char author[50]; int year; };
  2. Функция void addBook(Book*& library, int& count) — добавляет новую книгу (увеличивает массив динамически).
  3. Функция void removeBook(Book*& library, int& count, int index) — удаляет книгу по индексу.
  4. Функция void displayBooks(const Book* library, int count) — выводит все книги.
  5. Функция void findBooksByAuthor(const Book* library, int count, const char* author) — ищет книги по автору.
  6. В main() создайте меню для тестирования всех операций.
💡 Динамический массив: используйте new Book[count] и delete[].
Важно: При добавлении/удалении создавайте новый массив нужного размера и копируйте данные.

Многомерные массивы Матричные операции

Создайте программу для выполнения операций над матрицами:

  1. Реализуйте функцию void multiplyMatrices(const int A[][3], const int B[][3], int result[][3], int rows, int cols) — умножение двух матриц.
  2. Реализуйте функцию void addMatrices(const int A[][3], const int B[][3], int result[][3], int rows, int cols) — сложение матриц.
  3. Реализуйте функцию void scalarMultiply(int matrix[][3], int scalar, int rows, int cols) — умножение матрицы на скаляр.
  4. В main() создайте две матрицы 2×3 и 3×2 для демонстрации умножения, а также несколько квадратных матриц для сложения и умножения на скаляр.
  5. Выводите результаты на экран с помощью функции printMatrix.
💡 Многомерные массивы в параметрах: int matrix[][3] — необходимо указать размер второго измерения, чтобы компилятор мог вычислить смещение.
Пример вывода: Матрица A: 1 2 3 4 5 6 Матрица B: 7 8 9 10 11 12 Результат A * B: 58 64 139 154
💡 Важные моменты при работе с массивами в функциях:
  • При передаче массива в функцию всегда передаётся указатель на его первый элемент (массив не копируется).
  • Размер массива необходимо передавать отдельным параметром, так как функция не может его определить автоматически.
  • Использование const для параметра-массива гарантирует, что функция не изменит его содержимое.
  • Для передачи многомерных массивов необходимо указать размер всех измерений, кроме первого (или использовать указатели).
  • Ссылки на массивы (int (&arr)[10]) сохраняют информацию о размере массива, но требуют точного соответствия размера при вызове.
